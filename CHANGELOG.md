# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.2.0] — 2026-06-17

### Добавлено
- Подсчёт количества копирований каждого замечания в буфер обмена.
- Окно «Статистика копирования» с сортировкой замечаний по числу копирований.
- Кнопка статистики на панели инструментов главного окна.
- Поля `id` и `copy_count` в формате `.json` для хранения идентификатора замечания и счётчика копирований.

### Изменено
- Синхронизация замечаний между вкладками выполняется по стабильному идентификатору, а не только по тексту и категории.

## [1.1.0] — 2026-06-16

### Добавлено
- Документация по архитектуре приложения.
- Переименование тегов.
- Добавление замечания двойным кликом по пустому месту списка.

### Изменено
- Замечания сортируются по алфавиту.
- После сохранения остаётся открыта текущая вкладка.
- При смене вкладки сохраняются поисковый запрос и выбранные теги.

### Исправлено
- Сброс фильтров по кнопке «Очистить».
- Описание работы автодополнения тегов в `TagCompleter`.
