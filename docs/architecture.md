# Архитектура приложения

Документ описывает устройство приложения "Помощник нормоконтролёра" и связи между основными модулями.

## Общая схема

Приложение построено как настольная программа на PyQt5. Точка входа создаёт `QApplication`, главное окно и передаёт управление циклу событий Qt.

```text
main.py
  -> MainWindow
       -> Ui_MainWindow
       -> RemarkDialog -> Ui_RemarkDialog
       -> TabDialog    -> Ui_TabDialog
       -> utils.resource_path()
```

Основная логика сосредоточена в `MainWindow`: работа с файлами, вкладками, замечаниями, поиском, тегами, настройками и состоянием изменённости документа.

## Модули

`main.py`

Точка входа. Создаёт приложение, задаёт стиль `Fusion`, создаёт и показывает `MainWindow`.

`main_window.py`

Главный модуль приложения. Отвечает за:
- создание базовых вкладок "Все" и "Без категории";
- загрузку и сохранение `.txt` и `.json`;
- добавление, редактирование, удаление и копирование замечаний;
- добавление, переименование, удаление и перемещение вкладок;
- поиск по тексту замечаний;
- фильтрацию по тегам в режимах `AND` и `OR`;
- переименование тегов;
- сортировку замечаний;
- сохранение пользовательских настроек через `QSettings`;
- обработку горячих клавиш и части событий интерфейса.

`remark_dialog.py`

Диалог создания и редактирования замечания. Возвращает текст замечания, категорию и список тегов. Также содержит `TagCompleter`, который подсказывает теги при вводе списка через запятую.

`tab_dialog.py`

Диалог создания и редактирования вкладки. Возвращает имя вкладки и её позицию.

`utils.py`

Содержит `resource_path()`, единый способ получить путь к ресурсам. Функция работает и при запуске из исходников, и внутри сборки PyInstaller.

`ui_*.ui`

Исходные файлы интерфейса Qt Designer.

`ui_*.py`

Python-код, сгенерированный из `.ui` файлов утилитой `pyuic5`. Эти файлы описывают виджеты и начальные свойства интерфейса; бизнес-логика должна оставаться в обычных модулях.

## Данные в интерфейсе

Каждое замечание хранится как `QListWidgetItem`.

В item data используются роли:
- `Qt.UserRole`: категория замечания;
- `Qt.UserRole + 1`: список тегов.

Вкладка "Все" содержит клоны замечаний из остальных вкладок. Категорийные вкладки содержат оригинальные элементы. При изменении, удалении или переносе замечания код синхронизирует оригинал и клон по тексту и категории.

## Форматы файлов

`.txt`

Простой список замечаний, по одному замечанию на строку. Категории и теги в этом формате не сохраняются.

`.json`

Список объектов:

```json
[
    {
        "category": "Категория",
        "text": "Текст замечания",
        "tags": ["тег"]
    }
]
```

Категория "Без категории" используется для замечаний без пользовательской категории.

## Основные сценарии

Загрузка файла:

1. `load_file()` очищает пользовательские вкладки и списки.
2. В зависимости от расширения вызывает `read_from_txt()` или `read_from_json()`.
3. Создаёт элементы списков, заполняет категории и вкладку "Все".
4. Сортирует замечания и обновляет список тегов.

Сохранение файла:

1. `save_file()` или `save_file_as()` выбирает формат сохранения.
2. Для `.txt` при наличии категорий или тегов показывает предупреждение о потере данных.
3. `write_to_txt()` или `write_to_json()` записывает данные.
4. После успешной записи окно остаётся в текущем состоянии, а флаг изменённости сбрасывается.

Добавление замечания:

1. `add_remark()` открывает `RemarkDialog`.
2. По результату диалога создаёт item на категорийной вкладке.
3. Клон item добавляется во вкладку "Все".
4. Списки сортируются, теги обновляются, документ помечается изменённым.

Редактирование замечания:

1. `edit_remark()` открывает `RemarkDialog` для каждого выбранного замечания.
2. Обновляет текст, категорию и теги.
3. Если категория изменилась, переносит оригинал на новую вкладку.
4. Синхронизирует клон на вкладке "Все".

Фильтрация:

1. `filter_remarks()` получает поисковый запрос из `searchLineEdit`.
2. Собирает отмеченные теги из `tagListWidget`.
3. Для каждого item текущей вкладки проверяет совпадение по тексту и тегам.
4. Скрывает элементы, которые не прошли фильтр.

## Настройки

Через `QSettings("eluvesi", "NCA")` сохраняются:
- путь к последнему открытому файлу;
- видимость панели тегов;
- режим фильтрации тегов.

Настройки записываются при закрытии окна в `closeEvent()`.

## Правила изменения интерфейса

Основным источником разметки остаются `.ui` файлы. Если интерфейс меняется через Qt Designer, после этого нужно обновить соответствующий `ui_*.py` через `pyuic5`.

Логика приложения не должна добавляться в `ui_*.py`: при регенерации эти файлы могут быть перезаписаны. Обработчики сигналов и бизнес-правила должны находиться в `main_window.py`, `remark_dialog.py` или `tab_dialog.py`.
